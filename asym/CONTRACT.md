# 信息不对称面板 · 数据契约 v1

**核心命题**：面板不能展示"信息不对称"本身，只能展示**知情者留下的行为痕迹**。
所有面板围绕一个问题：**那些比你先知道的人，现在在做什么？**

> 这一句是全项目的设计红线。任何面板如果回答不了"这是谁的痕迹、为什么可观测"，
> 就不该出现在这个仪表盘里。

## ⚠️ 三个必须处理的数据陷阱（实测发现）

**1. 调研记录是"机构×场次"的展开表，`NUM` 是序号不是总数（最严重陷阱）**

实测 `普门科技`（2026-10-30）**260 条记录 = 11 个调研场次**，其中一场 `101` 条记录。
逐条核对发现 `NUM` 取值 1,2,3,…,101 **连续编号**——它是**参与机构的序号**，
不是机构总数。若按 `NUM` 求和会得到 5087 家（荒谬），若按行数当"调研次数"会得到
"被调研 101 次"（同样荒谬）。

**正确语义**：
- 一行 = 一家机构参与某一场调研
- `(股票, RECEIVE_START_DATE, RECEIVE_WAY_EXPLAIN)` 定义**一个场次**
- 该场次的**参与机构数 = 该组记录的行数**
- 调研场次总数 = 去重后的组数
- **`NUM` 字段一律不使用**（仅作序号，无统计意义）

必须按此口径实现，并以 `asym_test.py` 断言回归（用普门科技 260→11 这个真实样本）。

**2. `CHANGE_SHARES` 符号方向需确认**
字段可能是"变动股数（带符号）"或"绝对股数+另一方向字段"。**必须抽样核对**：
取几条已知减持记录，验证负值确实表示减持。不确定就标注 unknown，**不要假设**。

**3. 股东户数 `HOLDER_NUM_RATIO` 不是直觉**
实测看到 `278646.15%`（皇冠新材，新股上市户数暴增）这类极端值。
比率必须做**极值截断与分位化**，不能直接平均值聚合，否则一个新股毁掉全市场统计。

## 面板设计（4 个，每个都必须能回答"谁的痕迹"）

### P1 调研热度图
谁正在被密集拜访。
- 按 `(股票, 日期)` 去重后的**调研场次**
- 参与机构数（`NUM` 或同日同股记录数，需去重口径一致）
- 近 5 日 vs 近 20 日对比，标出"突然被密集调研"（异常上升）
- **诚实标注**：调研 ≠ 利好。它只证明"有人获得了非公开沟通机会"。

### P2 内部人投票
高管增减持的净方向与规模。
- 当日/近5日净增持金额、净减持金额、增持家数/减持家数
- 净减持集中的行业
- 关键提示：**减持原因要区分**（集中竞价 vs 大宗 vs 其他），大宗折价常是套现
- 只统计**变动金额有真实数值**的记录，`CHANGE_AMOUNT` 缺失不填 0

### P3 筹码集中度
股东户数变化 → 筹码流向少数人还是多数人。
- 户数环比下降的公司数 vs 上升的公司数（**比率做极值截断**）
- 户数下降 + 股价横盘 = 筹码收集的典型形态（需标注这是形态描述非预测）
- 披露是季度级，**必须显著标注数据滞后天数**

### P4 席位活跃度
龙虎榜营业部结构与游资动向。
- 活跃营业部 Top（买方/卖方出现次数、净额）
- 已知游资席位与机构专用席位的区分（若字段可得，否则标 unknown）

## 架构约束（与主大盘同构）

```
asym/
├── asym_fetch.py    # 取数（复用主项目 fetch 的 UA/重试/并发思路）
├── asym_metrics.py  # 纯函数，无 IO/网络
├── asym_render.py   # 纯函数，输出 HTML 面板
└── asym_test.py     # 端到端 + 数据陷阱回归测试
```

**必须复用主项目的三条原则**：
1. 取不到 → None，绝不填 0 冒充（限 `limitations`）
2. 每个面板显著标注数据滞后天数与口径
3. 数字必须能追溯到具体字段；渲染层不得自行重算口径

## 明确不做

- ❌ 不做"内幕交易"推断。调研/减持都是**合法公开披露**行为，不能暗示违法。
- ❌ 不做"跟着买"的建议。只展示行为痕迹。
- ❌ 不用缺失数据推算。宁缺不假。
- ❌ 不把滞后数据包装成先知信号。
