# 背离解释器

> 把资金背离信号（今日流入但中期流出）放回真实商业背景，看四层证据是**互相印证**还是**互相矛盾**。

## 一句话定位

**它不给你答案，它让你看清做判断需要看什么。**

单看资金背离，你只会纠结"该不该信"。三层摊开后：
- 资金在撤 + 估值偏高 + 报道偏空 → 背离**可信**
- 资金在撤 + 估值偏低 + 报道偏多 → 背离**可能是错杀**

## 用法

```bash
python3 explain_render.py     # 生成 out.html（取数+计算+渲染一条龙）
python3 explain_test.py       # 27 项测试
```

## 三层数据（全部实测确认）

| 层 | 数据源 | 覆盖 | 可靠性 |
|---|---|---|---|
| **资金流** | 主项目 metrics | 496 板块 | ✅ 全额 |
| **估值** | `RPT_VALUEINDUSTRY_DET` | **127 板块**（27%） | ✅ 2387 交易日历史，PE 分位可算 |
| **新闻** | 东财搜索 API | 126/126 | ✅ 需剔除同源报道与 ETF 软文 |
| **财报** | 业绩预告 | **约 4%** | ⚠️ 仅作日历提示，且存在系统性偏乐观 |

## 三个已否决的方案（都有实测依据）

| 方案 | 否决原因 | 证据 |
|---|---|---|
| 用成分股自算 PE 作代理 | 与官方口径**平均差 29.6%** | STAGE1B_VALUATION_PROXY.md |
| 板块级财报净利同比聚合 | 业绩快报仅 0.2%、预告仅 4% | STAGE1_VERIFICATION.md |
| 产业链图谱 | 接口不存在（探测 5+ 种全失败） | DESIGN.md |

## 核心设计约束

1. **有多少证据说多少话**：两层不能包装成三层结论
2. **缺层不推算**：没有估值就标"不可得"，不造代理值
3. **新闻不做情感分析**：只做可核对的事实标签命中
4. **剔除同源报道**：否则等于拿数据源 A 验证数据源 A
5. **财报标注选择性偏差**：预告是自愿披露，全样本正向占比约 72%

## 与主项目的关系

主项目的资金流信号**已被证伪**（120 交易日、5.4 万样本、预注册检验未通过，见 `../PREREGISTRATION.md`）。

解释器的价值不在于"让信号变准"，而在于**把纯技术信号放回商业语境**——
它回答的是"为什么会背离"，不是"该不该买"。
