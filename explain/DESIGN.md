## 0. 一句话设计

**不做"数据大融合"（那是空话），做"同一坐标下的四层交叉检验"。**

对一个给定的板块 + 日期区间，同时取四层证据：

```
资金流（已有） → 估值（可得） → 新闻（可得） → 财报（可得）
                        ↓
        四层是「互相印证」还是「互相矛盾」？
```

产出不是"买/不买"，而是**「这个信号的可信度打分 + 事实陈列」**。

---

## 1. 为什么是"背离解释器"而不是"三层模块"

三条理由，都是实测得出的：

**① 分开做会变成三个孤立面板，没有联动价值**
如果只是"估值面板 / 新闻面板 / 财报面板"各做一个，用户还是要自己去脑内拼合。
真正的价值在于**同一个问题上四个视角同时说话**。

**② 已有明确的"锚点问题"**
系统已经产出背离信号（今日流入但 5/10 日流出，实测 73 个板块/日）。
每个背离都是一个天然的问题："为什么会有这个矛盾？"
四层数据正好可以为它提供解释或反证。

**③ 产业逻辑层不可得，硬做会变成编造**
实测：产业链图谱接口**不存在**（探测 5+ 种 reportName 全部失败），
`SELECTED_BOARD_REASON` 字段存在但全为 None。
所以产业逻辑只能做**代理推断**，且必须显著标注。把它伪装成真数据是欺骗。

## 2. 实测数据边界（这是文档的地基）

| 层 | 数据源 | reportName / 接口 | 实测状态 | 覆盖 |
|---|---|---|---|---|
| **资金流** | 东财板块资金流 | `push2his` fflow/daykline | ✅ 已集成 | 496 板块 × 120 交易日 |
| **估值** | 行业估值 | `RPT_VALUEINDUSTRY_DET` | ✅ 可用 | **127 板块 × 多个交易日**（30万条） |
| **财报** | 业绩快报 | `RPT_FCI_PERFORMANCEE` | ✅ 可用 | 全市场 |
| | 主营构成 | `RPT_F10_FN_MAINOP` | ✅ 可用 | 全市场 |
| | 主要财务指标 | `RPT_F10_FINANCE_MAINFINADATA` | ✅ 可用 | 全市场 |
| **新闻** | 东财搜索 | `search-api-web.eastmoney.com` | ✅ 可用 | 可翻页，实测可达 3 页前 |
| **成分股** | 板块成分 | `fs=b:BK{code}` (push2) | ✅ **可用** | 电力设备实测 414 只 |
| **产业逻辑** | 产业链图谱 | — | ❌ **不可得** | 只能做代理推断 |

### 2.1 分类体系差异（必须写进代码）

**估值数据是申万分类（127 个，代码 `016xxx`），资金流是东财板块分类（496 个，代码 `BKxxxx`）。两套体系不同。**

实测对齐结果（2026-11-04 验证）：
- 名称精确匹配：**125 / 496（25.2%）**，其中 **125 个 PE 全部可用**
- 估值独有（我们没）：1 个（"种植业"）
- 我们独有（估值没）：369 个

**这意味着**：
- ✅ 覆盖了全部申万一级/二级主力板块（最有分析价值的 125 个）
- ❌ 另外 369 个是东财细分三级板块，无估值数据
- **对齐方式只能是「名称精确匹配」，不允许模糊匹配**（避免"电池"匹配到"电池化学品"这种错配）

### 2.2 估值层（实测充分，是最好的锚）

**PE 历史深度实测：回溯到 2020-08-24，共 1500 个交易日。**

例：光伏设备 PE 历史分位计算
```
历史 PE: min 15.1 / p25 28.3 / 中位 46.3 / p75 58.9 / max 93.2
当前 PE 44.4 → 历史分位 46%（中性区间）
```
→ **PE 历史分位可算，且是有意义的估值锚**，这是四层里最坚实的一层。

### 2.3 新闻层的关键约束

- 字段：`date / title / content / mediaName / url`
- 可翻页，实测第 3 页已到 2026-09-29
- **标题与正文中的关键词被 `<em>` 标签包裹**（如 `<em>电力设备</em>`），需清洗
- **禁止做情感分析**——中文财经新闻的情感打分是不可靠的伪科学。
  只做**事实抽取**：标题里出现"净流入居首""价格回调""三季报比拼"这类可核对的事实。

### 2.4 财报层的关键约束（实测已补全路径）

**业绩快报按个股组织，要变成板块级必须先有成分股映射。** 实测该路径可用：

```
① 板块成分股
   GET push2.eastmoney.com/api/qt/clist/get?fs=b:BK1200
   → 电力设备 414 只成分股（含代码/名称）
   备用：RPT_F10_CORETHEME_BOARDTYPE 按 BOARD_NAME 过滤，同样返回 414 条

② 个股业绩快报
   GET datacenter-web?reportName=RPT_FCI_PERFORMANCEE
   → 39,512 条，字段含 REPORT_DATE / TOTAL_OPERATE_INCOME / PARENT_NETPROFIT

③ 聚合：按成分股集合，对业绩快报做加权汇总
   - 板块净利同比 = Σ成分股净利 / Σ成分股去年同期净利 - 1
   - 必须记录样本覆盖率（有财报的成分股 / 全部成分股）
```

**必须标注的滞后**：
- 业绩快报是季度级（最近为 2026Q3，报告期 2026-09-30）
- `lag_days` = 计算日 − 该财报公告日
- 主营构成是年报/半年报级，滞后更久
- **不可当作实时数据**

## 5. 一致性判定的逻辑（核心算法，必须可复核）

**原则：不做黑箱打分。每个方向判定都给出具体数值依据。**

### 5.1 四层各自的"方向"

| 层 | 方向判定 | 依据 |
|---|---|---|
| 资金流 | 中期(5/10日)净额符号 | 已有 |
| 估值 | PE 历史分位 <30%=偏低 / >70%=偏高 | 用该板块自身历史分位 |
| 新闻 | 事实标签的**净倾向** | 见 5.2 |
| 财报 | 最近一期净利润同比符号 | 业绩快报 |

### 5.2 ⚠️ 新闻层的致命陷阱：自我引用循环（实测发现）

用真实背离样本（电力设备）实测搜索，30 条里大量是本类标题：

```
2026-11-03 4个行业主力资金净流入，电力设备行业净流入规模居首
2026-11-03 电力设备行业今日净流入资金35.64亿元
2026-10-28 电力设备行业资金流出榜：宁德时代等净流出资金居前
2026-10-21 电力设备行业今日跌3.67%，主力资金净流出57.74亿元
```

**这些报道的原始数据就是东财资金流本身。**
若把它们当作"新闻层的独立证据"，就是**拿数据源 A 去验证数据源 A**，
四层交叉检验会退化成一个假的"一致性"。

**必须做新闻过滤，剔除同源资金流类报道：**

```python
# 剔除规则（标题命中即排除）—— 实测迭代两版后确定
FLOW_SELFREF = [
    "资金流出榜", "资金流入榜", "资金流向日报", "半日主力资金",
    "主力资金净", "净流入资金", "净流出资金", "净流入规模",
    "资金净流入", "资金净流出", "加仓", "抛售", "主力资金",
    "资金流向", "个股异动",   # "异动"类多为资金异动
]
```
**实测效果**（电力设备，30 条）：剔除 13 条 → 保留 17 条。
保留样本质量：
```
湘财证券：电力设备行业部分细分环节供需格局与盈利能力有望改善   ← 研报观点
从线缆到备电 算力"买电"重塑电力设备企业成长逻辑                ← 产业逻辑
特变电工发布固态变压器，电力设备厂商为何押注AI数据中心？        ← 产业事件
华明装备：前三季度电力设备收入同比增长13.55% 海外业务增长亮眼  ← 公司公告
```

**注意**：过滤规则是**启发式**的，无法保证 100% 剔净（如"3.54亿元资金今日流入"
仍会漏过）。因此**必须把剔除前后的条数和样本都展示给用户**，让其自行判断。

**保留的是有独立信息量的报道**：
- 公司公告类（"华明装备：前三季度电力设备收入同比增长13.55%"）
- 产业事件类（"特变电工发布固态变压器，电力设备厂商为何押注AI数据中心"）
- 价格/供需类（"从21万到9万，动力电池原料价格大幅回调"）
- 券商研报类（"湘财证券：电力设备行业部分细分环节供需格局与盈利能力有望改善"）

**修正后实测**：剔除同源报道后，电力设备剩余高质量报道约 12 条/30 条，
涵盖公告、产业事件、研报三类，**这才是有独立验证价值的内容**。

### 5.2.1 新闻倾向怎么算（不用情感分析）

只用**可核对的短语命中**：

```
正面事实标签：净流入居首 / 中标 / 订单 / 涨价 / 扩产 / 产能紧张 / 供需改善 / 净利增长
负面事实标签：净流出 / 价格回调 / 降价 / 减产 / 亏损 / 预减 / 库存高企 / 需求疲软
中性标签：    公告 / 人事 / 股权 / 例行披露
```

倾向 = 正标签命中数 − 负标签命中数。**并且原文链接必须保留**，用户可自行核对。

**必须标注**：这是"报道口径的倾向"，不是"事实的真相"，且**已剔除同源资金流报道**。

**并必须在界面上显示**：
```
新闻：30 条原始 → 剔除同源资金流报道 18 条 → 有效 12 条
```
让用户知道这一层的证据基础有多薄。

### 5.3 一致性打分

```
一致层数 = 方向与"资金流出"同向（即解释背离）的层数
```

- 四层都指向"基本面转弱" → **一致，背离可信**（score 高）
- 资金流出但新闻/财报都正面 → **矛盾，背离存疑**（score 低，需人工判断）
- 数据缺失层 → 降级，标注"证据不足"，不推算

**打分公式必须公开在代码里，且输出每个贡献项。**

## 7. 必须写进代码的硬约束

| 约束 | 原因 |
|---|---|
| 估值对齐**只做名称精确匹配** | 模糊匹配会把"电池"错配到"电池化学品" |
| 新闻**禁止情感分析** | 中文财经情感打分不可靠，会产出伪信号 |
| 产业逻辑**必须标注"代理推断"** | 真图谱不可得，伪装成真数据是欺骗 |
| 财报必须标 `lag_days` | 季度数据，不标注会被当成实时 |
| 缺层**不推算** | 三层缺一层就标"证据不足"，不脑补 |
| 每层输出的方向**必须附具体数值** | 防止黑箱打分 |
| 判定文案**禁止**买卖建议 | 与主项目同一合规红线 |

## 8. 测试计划（写完即测）

1. **对齐覆盖率**：125/496 名称匹配是否稳定；不匹配的板块必须优雅降级
2. **名称错配防护**：注入"电池"与"电池化学品"同时存在，验证不会互相串数据
3. **新闻标签**：用真实样本验证正/负标签命中不误判（如"净流出居首"不能被算作正面）
4. **缺失降级**：三层各缺一层，输出必须显示"证据不足"而非硬给结论
5. **措辞合规**：断言不得出现"建议买入/卖出/必将"等（沿用主项目语境感知判定）
6. **时间对齐**：财报 `lag_days` 计算正确；新闻窗口与资金流区间一致

## 11. 最重要的一句

这个工具的价值**不在于"给出解释"，而在于"暴露矛盾"**。

单看资金背离，你只会纠结"该不该信"。
四层摊开后，如果资金在撤但业绩在涨、估值不贵、新闻中性——
你就知道这个背离**可能只是估值消化**，不必恐慌。

**它不替你做决定，它让你看清做决定需要看的东西。**
