# 补充验证：估值代理方案的否决

验证时间：2026-11-04 15:30
背景：STAGE1 发现背离板块只有 25-40% 能匹配官方估值数据。
本文档记录"用成分股自算 PE 作代理"这个替代方案的验证结果。

---

## 结论：代理方案不可用

| 方案 | 实测结果 | 判定 |
|---|---|---|
| 市值加权 PE（成分股） | 严重失真：传媒 1374、计算机 387 | ❌ |
| **中位 PE（成分股）** | 与官方行业 PE **平均差 29.6%**，最大差 70% | ❌ **仍不可靠** |
| 官方行业估值（127 板块） | 权威口径 | ✅ 唯一可用 |

### 市值加权为什么失真

微利股的 PE 极高（如 PE=2000），而市值又不小，会把加权均值拉到荒谬水平：
```
传媒: 市值加权 1374.0  vs  中位 48.3   差 28 倍
计算机: 387.4  vs  73.1              差 5.3 倍
```
**这是 PE 指标本身的数学缺陷**（分母趋近 0 时比值爆炸），不是计算错误。

### 中位 PE 为什么也不可靠

中位数避开了极端值，但它衡量的是"典型公司"，而官方行业 PE 是
"市值加权 TTM"，两者**在经济含义上就不同**：

```
自动化设备: 官方 181.1  vs 代理中位 54.4   差 -70.0%
小金属:     官方  52.5  vs 代理中位 23.8   差 -54.6%
消费电子:   官方  34.3  vs 代理中位 51.3   差 +49.3%
```

平均绝对差异 **29.6%**。用这样的代理去做"估值偏高/偏低"的判定，
结论会有三分之一以上的误差 —— 那还不如不做。

**结论：不造代理。没有官方估值数据的板块，就如实标注"估值数据不可得"。**

---

## 对设计的最终影响

### 三层方案的实际可用率

```
背离信号 73 个
  ├─ 有官方估值   21 个 (29%)
  └─ 无官方估值   52 个 (71%)  ← 只能输出两层
```

**这意味着解释器要接受"大部分情况只有两层"这个现实。**

### 分层输出的设计

不追求"每个板块都有三层"，而是**按可用层数给出不同强度的结论**：

| 可用层数 | 输出形态 | 结论强度 |
|---|---|---|
| 3 层（资金流+估值+新闻） | 完整交叉检验 | 强 |
| 2 层（资金流+新闻） | 部分交叉检验 | 中，标注"缺估值" |
| 1 层（仅资金流） | 只陈列事实 | 弱，明确说"证据不足" |

**禁止**：把两层的结果包装成三层的结论。

---

## 为什么这个否决很重要

在写代码之前花 20 分钟验证，避免了两类错误：

1. **错误一**：真的去用代理 PE，产出带 30% 误差的"估值判定"，
   而用户不知道这是估算值 → 误导。
2. **错误二**：为了"每板块三层"的完整性，去拼接不同口径的数据，
   制造一个看起来完整、实则拼凑的系统。

**诚实的做法是承认 71% 的板块只有两层。** 这比假装完整好。
